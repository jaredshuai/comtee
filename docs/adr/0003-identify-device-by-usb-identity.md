# 设备用稳定身份认，不认 COM 号

同一根 USB 串口 gadget 插到不同口或重启后，COM 号会变；VID:PID 与序列号一般不变。蓝牙串口没有 USB VID:PID，Windows 的 BTHENUM 硬件标识提供了配对设备与服务实例的稳定键。串通按 USB 身份或 BTHENUM 身份选择设备，COM 号只作为此刻打开它的路径。线路钉的是人端入口与设备身份，不是 COM 号。设备暂时消失只进入等待设备，不拆线路；人端入口继续听，已连着的人端不断开；同一身份重新出现后即使 COM 号变了也对上。蓝牙重新配对后若 Windows 生成了新的硬件标识，需要在设置里重新选择设备。
