# 人端按线路各留一个本机 TCP，Agent 走命名管道

人端必须走 TCP：终端用标准 Telnet 连本机端口，不绑定 MobaXterm。每条线路独占一个人端入口，所以串通上会有多个本机 TCP 口（例如 2222 对一条线路、3333 对另一条），不是全局只留 2323。每多一个对外 TCP 口，占用冲突和误连就多一分，因此不为面板、不为 Agent 再开 TCP。面板与串通同进程，按钮直接调函数。Agent 用 Windows 命名管道，不进 TCP 端口表；串通共用一根管道，读写时指名线路。操作哪条线路由人当场告诉 Agent，不靠串通猜测。Cursor 里的 MCP 只做 stdio 与管道之间的翻译，自己不打开设备；另备 skill，防止 Agent 去直接打开设备。v1 只做 Win11。
